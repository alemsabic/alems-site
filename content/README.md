# Content Directory

This folder is **automatically synced** from the separate content repository.

## Content Repository
**Repository**: [Dein Kopf. Dein Projekt. Deine KI.](https://github.com/alemsabic/Dein-Kopf.-Dein-Projekt.-Deine-KI.)

## Important
⚠️ **DO NOT edit files in this folder directly!**

All content changes should be made in the content repository. Changes here will be overwritten on the next sync.

## How it works
1. Push changes to the content repository
2. GitHub Action automatically syncs content to this folder
3. Cloudflare Pages rebuilds and deploys the site
4. Changes appear on https://ale.ms within 1-2 minutes

## Manual Sync (if needed)
If automatic sync fails, you can manually trigger it:
1. Go to: https://github.com/alemsabic/Dein-Kopf.-Dein-Projekt.-Deine-KI./actions
2. Select "Sync Content to Quartz" workflow
3. Click "Run workflow"
