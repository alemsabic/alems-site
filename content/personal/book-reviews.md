3. **Solitude matters**: Regular time away from screens is essential

### "The Pragmatic Programmer" by Hunt & Thomas

**Rating**: ⭐⭐⭐⭐⭐
**Completed**: January 2024

#programming #software-development #craft

#### Technical Insights

- **DRY Principle**: Don't Repeat Yourself - every piece of knowledge should have a single representation
- **Orthogonality**: Change one thing without affecting others
- **Tracer bullets**: Build small working systems end-to-end

#### Code Quality Tips

```python
# Bad: Magic numbers
if user.age > 65:
    apply_senior_discount()

# Good: Named constants
SENIOR_AGE_THRESHOLD = 65
if user.age > SENIOR_AGE_THRESHOLD:
    apply_senior_discount()
```

## Reading Tips

#productivity #learning

### Active Reading Techniques

1. **Preview**: Scan table of contents and index first
2. **Question**: Form questions before each chapter
3. **Summarize**: Write key points in your own words
4. **Review**: Revisit notes after one week

### Note-Taking System

- **Highlights**: Mark important passages
- **Margin notes**: Quick thoughts and connections
- **Chapter summaries**: One paragraph per chapter
- **Action items**: Concrete next steps
