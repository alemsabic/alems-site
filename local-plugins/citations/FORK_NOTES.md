# Local fork: citations

Forked from https://github.com/quartz-community/citations at commit
`5db598448105ee791665ff3b5e4c35b285a85296` (main branch, 2026-07-26).

## Patch applied (`src/transformer.ts`)

Added `showTooltips`/`tooltipAttribute` to `CitationsOptions` and passed them through to the
underlying `rehypeCitation` call. Upstream's wrapper hand-picks a fixed set of fields
(`bibliography`, `suppressBibliography`, `linkCitations`, `csl`, `lang`) rather than spreading
`opts`, so these two real `rehype-citation` options (confirmed via the library's own README:
`options.showTooltips` / `options.tooltipAttribute`) were silently dropped even though v4 relied
on them — `data-tooltip` is generated by `showTooltips: true, tooltipAttribute: "data-tooltip"`,
and our own `local-plugins/site-scripts`' `tooltips.inline.ts` decodes the resulting HTML entities
client-side. Without this fork, that decode script has nothing to decode.

**Found via real browser/build testing, not static analysis**: initially assumed these were v4-only
custom additions and dropped them in Phase D. Caught while checking a citation's actual rendered
HTML in the dev server output — no `data-tooltip` anywhere on the site — and traced it back through
`rehype-citation`'s README to confirm they're real upstream options this wrapper just doesn't expose.

Everything else (bibliography-link popover suppression, German locale auto-derivation) is unchanged
from what's already built into upstream — see the Phase E notes in `upgrade.md` for that finding.
